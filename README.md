# RePlay

### Personalized Game Discovery & Gaming Analytics Platform

RePlay is a web-based gaming platform designed to help players discover games based on their interests, gaming preferences, and playstyle. It combines personalized recommendations, game discovery, player analytics, and gaming insights into one interactive platform.

## Features

*  **Personalized Game Recommendations** — Discover games based on your preferences and playstyle.
*  **Game Discovery** — Explore games across different genres and categories.
*  **Player Analytics** — View gaming statistics and insights through interactive visualizations.
*  **AI-Powered Recommendations** — Get intelligent suggestions based on your gaming interests.
*  **Game Library** — Organize and keep track of games you're interested in.
*  **Gaming Insights** — Understand your gaming habits, genres, and preferences.
*  **Interactive Gaming UI** — Immersive gaming-inspired interface with animations and responsive design.
*  **Responsive Design** — Works across desktop, tablet, and mobile devices.

##  Tech Stack

* **Frontend:** React.js
* **Build Tool:** Vite
* **Styling:** CSS
* **Charts & Analytics:** Recharts
* **Backend / Database:** Supabase
* **Authentication:** Supabase Authentication
* **Version Control:** Git & GitHub

##  Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/Replay-Gaming-Platform.git
cd Replay-Gaming-Platform
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env` file in the root directory:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

> Never commit your `.env` file or expose private API keys and service-role keys.

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal, usually:

```text
http://localhost:5173
```

##  Project Objective

The goal of RePlay is to make game discovery more personalized and meaningful. Instead of relying only on popular or trending games, RePlay focuses on understanding a player's interests and preferences to provide relevant recommendations and useful gaming insights.
